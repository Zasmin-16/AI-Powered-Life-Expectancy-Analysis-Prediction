## 📌 Project Overview

Life expectancy is influenced by multiple health, economic, and social factors.  
This project uses **WHO life expectancy data (2000–2015)** to analyze global trends and build a **machine learning model** that predicts life expectancy.

The best-performing model is deployed using **Flask** with a **modern web UI**, allowing real-time predictions.

---

## ✨ Key Features

- Exploratory Data Analysis (EDA)
- Data Cleaning & Preprocessing
- Machine Learning Model Training
- XGBoost model with **~96% R² accuracy**
- Flask-based Web Application
- Modern UI using Tailwind CSS
- Real-time Life Expectancy Prediction

---

## 🧠 Machine Learning Details

- **Algorithms Used**
  - Random Forest Regressor
  - XGBoost Regressor (Best Model)

- **Evaluation Metrics**
  - R² Score: ~0.96
  - RMSE: ~2 years

- **Target Variable**
  - Life Expectancy (Years)
